# Drill C++

Practice site for 26 C++ array and matrix problems. Write code in the page, press **Run** to try your own input, or **Submit** to check it against hidden tests.

- Real g++ (C++17, -O2) compiles and runs your code. The page sends it to the free Compiler Explorer service (Wandbox is the backup), so you need an internet connection.
- **Timed challenge**: pick a time limit. The problem restarts from an empty template with a countdown. If the clock runs out before every test passes, the problem is locked until you redo it.
- Your code, solved problems and best times are saved in your own browser only.

## Put it online with GitHub Pages

1. Create a new **public** repository on github.com.
2. Upload `index.html` and `README.md`.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute the site is at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

You can also just open `index.html` on your computer.
